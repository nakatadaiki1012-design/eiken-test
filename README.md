# 英検ラボ

英検 **4級・3級・準2級・2級・準1級** の筆記試験対策 Webアプリです。
`index.html` をブラウザで開くだけで動きます（インストール不要）。見た目は「論理表現ラボ」とそろえた方眼ノート風です。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/eiken-test/

### 📚 単語・熟語の量と えらび方

| 級 | 単語 | 熟語 | 合計 |
|---|---|---|---|
| 4級 | 1,457 | 293 | 1,750 |
| 3級 | 1,503 | 449 | 1,952 |
| 準2級 | 2,153 | 591 | 2,744 |
| 2級 | 2,328 | 703 | 3,031 |
| 準1級 | 3,227 | 802 | 4,029 |

**その級までに 学ぶ 単語の 合計**（同じ語は 1 回だけ数える）：4級 1,457 → 3級 2,486 → 準2級 4,169 → 2級 6,495 → 準1級 **9,722 語**（熟語は 2,449 個）。合格に 必要と いわれる 目安（4級 約 1,300・3級 約 2,100・準2級 約 3,600・2級 約 5,100・準1級 約 7,500〜9,000 語）を すべての級で こえています。

4級・3級には、上の級に入っている 基本の語のうち 中学で習う 基本の語（agree・explain・park・weather・look forward to など）も **写して** 入れています（`js/data/zz-share.js`・`zz-share2.js`。2級・準2級にも 上の級の よく出る 熟語を 写しています。上の級にも 残るので、同じ語が 2 つの級に 出ることがあります）。4級・3級の 解説は、中学生向けに とくに やさしい 日本語で 書いています。

市販の英検単語帳（1 冊 1,500〜1,900 項目）より 多い量です。リスニングに出る 生活の語（receipt・refund など）や、よく出る 語の 仲間（decide → decisive など）も 入れました。写した語を のぞけば、級の あいだに 重なりは ありません。

**どうやって 確かめたか**：英語の単語を 難しさで 分けた 公開リスト（CEFR-J Wordlist／Octanove Vocabulary Profile）と くらべました。英検の級と CEFR の 目安は 準2級 ≒ A2〜B1、2級 ≒ B1〜B2、準1級 ≒ B2〜C1 です。

| | はじめ（200 語ずつ） | 第 1 弾 | 第 3 弾 | 今 |
|---|---|---|---|---|
| A2 の単語のうち 入っている数 | 139 / 1,272 | 478 | 633 | **1,097** |
| B1 | 194 / 2,174 | 957 | 1,208 | **1,743** |
| B2 | 114 / 2,490 | 609 | 1,055 | **1,704** |

- 各級の 単語の むずかしさも 目安どおりです（準2級は A2・B1 が 9 割、2級は B1・B2 が 9 割、準1級は C1・C2 と リストにない 上級語が 9 割）。
- 残りの A2 は 中学で習う 基本語（3級まで）、B1・B2 の残りは 英検に あまり出ない語や 準1級より上の語が 多くなっています。
- **英検準2級の 単語リストとの 照合**：英語漬け.com「英検準2級の英単語」（全 1,480 語）の No.1〜665 と くらべ、2級・準1級に 入れていた 174 語（disaster・survey・rely on など）を 準2級へ 移し（`js/data/zz-moves.js`）、なかった 156 語・熟語を 足しました。いまは この 665 語のうち、前置詞・接続詞（via・till・whether など 11 語）と 英検に 出にくい 2 語を のぞく **すべてが 準2級に** 入っています。No.666 から先は まだ 照合していません。
- 英検の 過去問そのものの 出た回数は 公開されていないので、「本番に出る語 100%」を 保証するものでは ありません。

### 🧠 イメージと 覚え方（すべての 単語・熟語）

| | 中身 | 例（acquire） | 入っている数 |
|---|---|---|---|
| 🧠 コアの意味 | 辞書の意味を ならべず、1 つのイメージで「なぜ その意味か」 | 外にあるものを「求めて、自分のものにする」 | すべて |
| 🎬 イメージの場面 | 頭に 絵を 描ける 具体的な 場面 | アメリカに引っこした幼い妹が、半年で英語をぺらぺら話すようになっていた | すべて |
| ➡️ 意味の広がり | コアから 実際の 意味へ 矢印で | 求めて自分のものに → 言葉・技術を習得する → 物・会社を得る | すべて |
| 🧩 部品の図 | 本当の 語源の 部品を ブロックで（熟語は 動詞 × 前置詞） | ac（～へ）＋ quire（求める）＝ acquire | 7,645 |
| ⚖️ にている語との ちがい | まぎらわしい 語との 使い分け | get は何でも「手に入れる」、acquire は努力や時間をかけて身につける | 6,627 |
| 👪 なかまの語 | 同じ部品・同じコアの 語 | require・inquire | 7,689 |
| 🔑 覚え方 | 本当の語源・知っている語・カタカナ語・場面 | question（答えを求める）と同じ仲間 | すべて |
| 絵文字 | コアのイメージを 絵文字で | put off 📅➡️ | 5,512 |
| 前置詞の図 | run **out** of・give **up** などの 小さな語の イメージ図（30 種類） | | 動詞＋前置詞の 熟語 |

- **どこで 見られるか**：まちがえたとき（ぜんぶ 大きく）・📖 覚えるカード（ぜんぶ）・📋 一覧（ひらくと ぜんぶ）。正解したときは コア・部品・広がり だけ 出して、残りは「🎬 場面・ちがい・覚え方を 見る」で ひらく。
- **🧩 部品で覚える**（級の メニュー）：同じ部品を もつ 単語を まとめて 見る 画面。「⬅️ 頭に つく 部品」は、**イメージの にた 仲間で まとめて** 出します（ad- ac- af- ap-＝「～へ」、con- com- col- cor-＝「いっしょに」、in- im- il- ir-＝「〜でない」など 約 20 仲間。仲間ごとに 図・コアの 意味・形が かわる わけ・単語の 一覧つき。仲間の 一覧は `js/prefix.js`）。つづけて「🌱 語根」も **意味の 仲間** で まとめます（spect・spec・vis＝見る、port・fer＝運ぶ、fact・fect＝作る など 約 35 仲間）。「➡️ おしりに つく 部品」は **はたらき（名詞・人・形容詞・動詞・副詞）** で まとめます。どの 仲間も 図か 絵・コアの 意味・単語の 一覧つき。まとめ きれなかった 部品は 下に「1 つずつ」出ます。
- 語源が あやしいものには 部品の図を つけていません（作り話の 語源は 入れない）。

### 💡 ヒント と 🧠 コアの意味の解説

- 問題の右上の **💡 ヒント** を押すと、答えは言わずに考え方のヒントが出ます（単語なら語源や場面、穴うめなら「どこを見ればいいか」、長文なら「どの段落を読むか」）。もう一度押すと、選択肢を **2 つにしぼります**。
- ヒントを見て正解した問題は、定着の段は上げずに「明日もう一度」出ます。
- 答えたあとは、いつも解説が出ます。**まちがえたとき**は、
  - 👆 **自分がえらんだ選択肢が、本当は何の意味か**
  - 🧠 **コアの意味**：辞書の意味をならべるのではなく、「なぜその意味になるのか」を 1 つのイメージで（例：issue ＝ 中から外へ出てくるもの → 発行する・問題）
  - 🔑 **覚え方**：本当の語源（接頭辞・語根）、カタカナ語、知っている単語とのつながり
  - 穴うめは 🧭 **考え方**（手がかり → 正解の語のコアの意味 → なぜこの文に合うか）と、4 つの選択肢それぞれの意味

  を大きく出します。正解したときは、コアの意味だけを小さく出します（覚え方はタップで開く）。

### 🚀 英単語ロケット（ひとりで遊ぶタイムアタック）

級のメニューの「🚀 英単語ロケット」から。論理表現ラボの「英文ロケット」と同じ景色・効果音です。

| コース | 出る問題 | 1 問の点数 |
|---|---|---|
| 📘 単語ロケット | 英語 → 意味（コンボ 10 からは 意味 → 英語 もまざる） | 50 |
| 📗 熟語ロケット | 熟語の意味 と 例文の（　） | 60 |
| ✏️ 穴うめロケット | 大問1 と同じ 4 択 | 110 |
| 🌈 ミックス | 単語・熟語・穴うめがまざって出る | それぞれの点数 |

- **🗻 高度 ＝ 点数**：東京タワー → スカイツリー → 富士山 → … → 宇宙ステーション → 月 → 火星 → … → 宇宙の果て。めじるしをこえると「突破！」。
- **⛽ 燃料（時間）**：60 秒から。コンボ 5 以上で正解すると燃料がふえ（コンボ 20 からは 2 倍）、ミスは −2 秒。40 秒をすぎると減りがだんだん速くなります（最大 ×3）。
- **🔥 BOOST**：15 問正解でメーターが満タン → 7 秒間 点数 ×2。
- **🔗 コンボの倍率**：10 で ×1.5、25 で ×2、50 で ×3。
- **💡 ヒント**：1 回のゲームで 3 回まで。選択肢を 2 つにしぼります（その問題の点数は半分）。
- **✕ まちがえたとき**：正解と 🧠 コアの意味が少し出て（その間は燃料が止まる）、4 問あとに同じ問題がもう一度出ます。まちがえた問題は「🔁 復習」にも入ります。
- **結果**：到達した場所・点数・正答率・最大コンボ・コースごとのベスト記録と、まちがえた問題の一覧（コアの意味つき）。
- パソコンでは 1〜4 キーで答え、H でヒント。効果音はメニューでオン／オフできます。

### 🏆 クラス対戦（先生の大画面で クラス全員が いっせいに）

論理表現ラボの クラス対戦と 同じ しくみです。ホームの いちばん下の「🏆 クラス対戦」から。

1. **先生**：「🚀 ロケット対戦の 部屋」か「🎯 クイズ大会の 部屋」を おす。4 けたの **部屋番号** と **QR コード** が 出ます（プロジェクターに 映す）。
   「⚙ 出題の 設定」で 次を えらびます（スマホからでも OK）。
   | 設定 | えらべるもの |
   |---|---|
   | 🎮 遊び方 | 🚀 ロケット対戦／🎯 クイズ大会 |
   | ⏱ 時間 | ロケット：30 秒〜5 分。クイズ：問題数 5・10・15・20 問、1 問 10・20・30 秒 |
   | 📚 級 | 4級〜準1級を **いくつでも**（同じ 語は 1 つに まとめて 出ます） |
   | 📖 出す問題 | ミックス／単語だけ／熟語だけ／穴うめだけ |
   | 🏆 映す人数 | 上位 3・5・10 人／全員 |
2. **生徒**：QR を 読みとる か、ホーム →「🏆 クラス対戦」→ 部屋番号と ニックネーム →「参加する」。先生の 画面に 名前が ならびます（ふさわしくない 名前は タップで 部屋から はずせます）。
3. **先生**：「▶ スタート」。
   - **ロケット対戦**：全員の 画面で 同時に 3・2・1 → GO!。時間は 先生が えらんだ 長さで 固定で、全員 **同じ 順番の 問題**。ロケットの 景色・コンボ・ブースト・ヒント（3 回）は 1 人用と 同じ。自分の 順位が 画面の 上に いつも 出ます。先生の 画面の ランキングは **リアルタイムで 動き**、1 位が かわると「👑 トップ交代！」。
   - **クイズ大会**：先生の 大画面に 問題 → 手元の 4 色の ボタンで 答える（早く 正解するほど 高得点・連続正解で ボーナス・パソコンは 1〜4 キー）。答え合わせで「どれを 何人が えらんだか」と 解説、ランキング → 次の問題。先生は →・スペース・PageDown でも 次へ 進めます。
4. 時間（または 最後の 問題）が 終わると **表彰式**（ドラムロール → 3 位 → 2 位 → 1 位）。生徒の 画面にも 順位と メダル。クイズは「📝 まちがえた 問題」も 出て、まちがえた 問題は「🔁 復習」にも 入ります。「📊 問題ごとの 正答率」「📋 結果を コピー」（Excel に 貼れる）もあります。
5. 「▶ 第2回戦 スタート」で 何回でも。「🏆 ハイスコア」タブで その部屋の 最高記録。終わったら「部屋を 閉じる」。

**準備**：全員の 点数を 集める データベース（Firebase Realtime Database・無料）が 必要です。このアプリは 論理表現ラボと **同じ データベース**（`js/config.js`）を そのまま 使えます（部屋の 名前の 頭に e を つけているので 論理表現ラボの 部屋と ぶつかりません）。自分の データベースを 使うときは、`js/config.js` を 書きかえるか、「🏆 クラス対戦」の「⚙ データベース」に URL を 入れてください。作り方は 論理表現ラボの README の「クラス対戦の準備」と 同じです。
部屋の 中身は 部屋番号を 知っている 人なら 読み書きできます。本名ではなく **ニックネーム** で 参加させてください（点数の ほかに 個人情報は 送りません）。

### 🔁 復習のしくみ

- 単語・熟語・穴うめで答えた問題は、自動で「復習」に入ります。
- ○ が続くと、次に出るまでの間が **1 → 2 → 4 → 7 → 15 → 30 日** とのびます。✕ はその日のうちにもう一度出ます。
- ○ が 3 回続いた単語・熟語を「定着」として数えます。
- 「今日の 10 語」は、復習の日が来たもの → まだ見ていないもの → まだ定着していないもの の順にえらびます。

## 記録について

記録と書いた英作文は、このブラウザの中（localStorage）にだけ残ります。ほかの端末とは共有されません。

## 注意

- 問題はすべてこのアプリのための自作問題です（過去問ではありません）。
- 英検の問題の形・時間・語数は変わることがあります。受ける前に英検の公式サイトで確かめてください。
- リスニング・二次試験（面接）は、まだ入っていません。
