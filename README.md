# 英検ラボ

英検 **準2級・2級・準1級** の筆記試験対策 Webアプリです。
`index.html` をブラウザで開くだけで動きます（インストール不要）。見た目は「論理表現ラボ」とそろえた方眼ノート風です。

**公開ページ（GitHub Pages を有効にした場合）**: https://nakatadaiki1012-design.github.io/eiken-test/

## できること

| メニュー | すること |
|---|---|
| 📘 単語 | 準2級 1,000 語・2級 1,100 語・準1級 1,200 語。「英語 → 意味」「意味 → 英語」の 4 択。答えたあとに例文と訳。🔊 で発音を聞ける |
| 📗 熟語 | 準2級 200 個・2級 250 個・準1級 300 個。「熟語 → 意味」か「例文の（　）に入る熟語」をえらぶ |
| ✏️ 大問1 穴うめ | 本番の大問1と同じ形の 4 択（級ごとに 45 問）。単語・熟語・文法でしぼりこめる。解説つき |
| 📖 長文 | Eメール・説明文を読んで答える（級ごとに 4 本）。本文の読み上げつき |
| ✍️ 英作文 | 「型を見る → 自分で書く（語数を自動で数える）→ チェック表 → 模範解答と和訳」 |
| 🏁 ミニ模試 | 穴うめ 10 問 ＋ 長文 1 本を続けて解く |
| 🔁 復習 | まちがえた問題・○をつけた問題が、日をあけて出てくる |
| 🚀 英単語ロケット | 単語・熟語・穴うめを どんどん正解して ロケットを宇宙へ飛ばすタイムアタック |

### 📚 単語・熟語の量と えらび方

| 級 | 単語 | 熟語 | 合計 |
|---|---|---|---|
| 準2級 | 1,000 | 200 | 1,200 |
| 2級 | 1,100 | 250 | 1,350 |
| 準1級 | 1,200 | 300 | 1,500 |

市販の英検単語帳（1 冊 1,500〜1,900 項目）に近い量です。級をまたいだ重なりはありません（同じ語は いちばん下の級に 1 回だけ）。

**どうやって 確かめたか**：英語の単語を 難しさで 分けた 公開リスト（CEFR-J Wordlist／Octanove Vocabulary Profile）と くらべました。英検の級と CEFR の 目安は 準2級 ≒ A2〜B1、2級 ≒ B1〜B2、準1級 ≒ B2〜C1 です。

| | 前（200 語ずつ） | 今 |
|---|---|---|
| A2 の単語のうち 入っている数 | 139 / 1,272 | 478 / 1,272 |
| B1 | 194 / 2,174 | 957 / 2,174 |
| B2 | 114 / 2,490 | 609 / 2,490 |

- 各級の 単語の むずかしさも 目安どおりです（準2級は A2・B1 が 9 割、2級は B1・B2 が 9 割、準1級は C1・C2 と リストにない 上級語が 9 割）。
- 残りの A2 は 中学で習う 基本語、B2 の残りは 準1級より上や 英検に あまり出ない語が 多くなっています。
- 英検の 過去問そのものの 出た回数は 公開されていないので、「本番に出る語 100%」を 保証するものでは ありません。

### 🧠 イメージと 覚え方

- **🧠 コアの意味**（すべての 単語・熟語）：辞書の意味を ならべるのではなく、1 つのイメージで「なぜ その意味になるか」。
- **🔑 覚え方**（すべて）：本当の語源、知っている語・カタカナ語との つながり、場面。作り話の語源は 入れていません。
- **絵文字のイメージ**（約 8 割）：コアのイメージを 絵文字で（例：accumulate 🏔️、at the expense of ⚖️）。
- **前置詞・副詞の イメージ図**：熟語（run **out** of・give **up** など）では、out・up・off・through など 30 の 小さな語の イメージを 図で 出します。
- **📖 覚えるカード**：単語・熟語の メニューから。英語を見て 思い出す → めくると 意味・絵文字・コアの意味・図・覚え方・例文 →「覚えた／もう一度」→ そのまま クイズで たしかめ。
- **📋 一覧**：各語の「🧠 イメージと 覚え方」を ひらいて 見られます。

### 💡 ヒント と 🧠 コアの意味の解説

- 問題の右上の **💡 ヒント** を押すと、答えは言わずに考え方のヒントが出ます（単語なら語源や場面、穴うめなら「どこを見ればいいか」、長文なら「どの段落を読むか」）。もう一度押すと、選択肢を **2 つにしぼります**。
- ヒントを見て正解した問題は、定着の段は上げずに「明日もう一度」出ます。
- 答えたあとは、いつも解説が出ます。**まちがえたとき**は、
  - 👆 **自分がえらんだ選択肢が、本当は何の意味か**
  - 🧠 **コアの意味**：辞書の意味をならべるのではなく、「なぜその意味になるのか」を 1 つのイメージで（例：issue ＝ 中から外へ出てくるもの → 発行する・問題）
  - 🔑 **覚え方**：本当の語源（接頭辞・語根）、カタカナ語、知っている単語とのつながり
  - 穴うめは 🧭 **考え方**（手がかり → 正解の語のコアの意味 → なぜこの文に合うか）と、4 つの選択肢それぞれの意味

  を大きく出します。正解したときは、コアの意味だけを小さく出します（覚え方はタップで開く）。

### 🚀 英単語ロケット（ひとりで遊ぶタイムアタック）

級のメニューの「🚀 英単語ロケット」から。論理表現ラボの「英文ロケット」と同じ景色・効果音です。

| コース | 出る問題 | 1 問の点数 |
|---|---|---|
| 📘 単語ロケット | 英語 → 意味（コンボ 10 からは 意味 → 英語 もまざる） | 50 |
| 📗 熟語ロケット | 熟語の意味 と 例文の（　） | 60 |
| ✏️ 穴うめロケット | 大問1 と同じ 4 択 | 110 |
| 🌈 ミックス | 単語・熟語・穴うめがまざって出る | それぞれの点数 |

- **🗻 高度 ＝ 点数**：東京タワー → スカイツリー → 富士山 → … → 宇宙ステーション → 月 → 火星 → … → 宇宙の果て。めじるしをこえると「突破！」。
- **⛽ 燃料（時間）**：60 秒から。コンボ 5 以上で正解すると燃料がふえ（コンボ 20 からは 2 倍）、ミスは −2 秒。40 秒をすぎると減りがだんだん速くなります（最大 ×3）。
- **🔥 BOOST**：15 問正解でメーターが満タン → 7 秒間 点数 ×2。
- **🔗 コンボの倍率**：10 で ×1.5、25 で ×2、50 で ×3。
- **💡 ヒント**：1 回のゲームで 3 回まで。選択肢を 2 つにしぼります（その問題の点数は半分）。
- **✕ まちがえたとき**：正解と 🧠 コアの意味が少し出て（その間は燃料が止まる）、4 問あとに同じ問題がもう一度出ます。まちがえた問題は「🔁 復習」にも入ります。
- **結果**：到達した場所・点数・正答率・最大コンボ・コースごとのベスト記録と、まちがえた問題の一覧（コアの意味つき）。
- パソコンでは 1〜4 キーで答え、H でヒント。効果音はメニューでオン／オフできます。

### 英作文の種類（2024年からの形）

| 級 | 1 問目 | 2 問目 |
|---|---|---|
| 準2級 | Eメールの返信（40〜50語） | 意見（50〜60語） |
| 2級 | 要約（45〜55語） | 意見（80〜100語・POINTS つき） |
| 準1級 | 要約（60〜70語） | 意見（120〜150語・POINTS つき） |

### 🔁 復習のしくみ

- 単語・熟語・穴うめで答えた問題は、自動で「復習」に入ります。
- ○ が続くと、次に出るまでの間が **1 → 2 → 4 → 7 → 15 → 30 日** とのびます。✕ はその日のうちにもう一度出ます。
- ○ が 3 回続いた単語・熟語を「定着」として数えます。
- 「今日の 10 語」は、復習の日が来たもの → まだ見ていないもの → まだ定着していないもの の順にえらびます。

## 記録について

記録と書いた英作文は、このブラウザの中（localStorage）にだけ残ります。ほかの端末とは共有されません。

## 注意

- 問題はすべてこのアプリのための自作問題です（過去問ではありません）。
- 英検の問題の形・時間・語数は変わることがあります。受ける前に英検の公式サイトで確かめてください。
- リスニング・二次試験（面接）は、まだ入っていません。
